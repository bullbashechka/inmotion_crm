## Definition of Done

- Все frontend-задачи используют Tailwind CSS для стилизации и shadcn/ui как базовый набор типовых UI-компонентов; исключения обоснованы в соответствующей задаче.
- Все 24 задачи приняты по своим проверяемым критериям; сквозной сценарий из разделов 32 и 35 PRD проходит без технического вмешательства.
- Backend проверяет права и область данных на каждом запросе; медицинские действия блокируются без действующих согласий.
- Составные операции атомарны, повтор запросов не создаёт дубликаты, конфликты версий не перезаписывают чужие данные.
- Медицинские, финансовые и аудиторские записи не удаляются физически и изменяются только предусмотренными связанными операциями или версиями.
- Проверены целевые объёмы, времена ответа, поддерживаемые браузеры, состояния ошибок и восстановление базы из резервной копии.
- Frontend и API развёртываются независимо; preview, demo и production изолированы; preview не получает production-секреты и не мигрирует рабочую БД.
- До production письменно подтверждены требования к размещению данных в Казахстане и допустимости обработки технических метаданных Cloudflare.
- Возможности разделов 3.2, 36 и 38 PRD не активированы в первой версии.
